# 体考跑步笔记 · 网站使用说明

一个纯静态多页网站，**不需要任何构建工具、不需要装依赖**，双击 `index.html` 就能在浏览器里打开。

---

## 一、文件结构

```
sports/
├── index.html        首页
├── exams.html        高考体育三大项（100米 / 立定跳远 / 铅球）
├── sprint.html       短跑专项技术（特色主打页）
├── library.html      训练干货知识库
├── about.html        关于 & 交流
├── css/
│   └── style.css     全站样式（配色、排版、响应式都在这里）
└── js/
    └── main.js       全站交互（菜单、手风琴、滚动动画）
```

---

## 二、怎么打开和编辑

**打开预览**：双击 `index.html`，用 Chrome / Edge / Safari 打开即可。

**编辑工具**（任选其一）：
- **VS Code**（推荐）：免费，安装后打开 `sports` 文件夹，改完保存，浏览器按 `F5` 刷新就能看到效果。
- **记事本 / Notepad++**：可以改，但没有代码高亮，容易改错标签。
- **在线编辑器**：如 CodeSandbox、StackBlitz，把文件传上去也能改。

## 三、最常改的几处（附具体位置）

### 1. 改网站名称 / 署名
每个页面都有页头 `brand-txt` 和页脚 `f-brand`，搜索关键词 **体考跑步笔记** 全部替换成你的名字即可。

> 5 个 HTML 文件都要改（用 VS Code 的「在文件中替换」Ctrl+Shift+H 一次性搞定）。

### 2. 改配色
打开 `css/style.css`，最上面的 `:root` 区块就是全部颜色变量：

```css
--blue: #005ED8;    /* 主色 · 竞技蓝 */
--red:  #E63946;    /* 辅助色 · 速度红 */
--ink:  #111111;    /* 强调字 · 深黑 */
--bg:   #FFFFFF;    /* 背景 · 纯白 */
--bg-soft: #F7F8FA; /* 浅灰背景 */
```

只改这几个值，**全站配色会一起变**，不用逐个文件找。

### 3. 改标题和正文
标题文字直接在 HTML 里搜索对应文字，比如首页主标题搜 `高考体育统考专项科普`。

段落文字夹在 `<p>...</p>` 或 `<h3>...</h3>` 之间，直接替换标签中间的内容，**不要动尖括号本身**。

### 4. 改评分标准 / 分数 / 成绩
- **三大项评分**：在 `exams.html` 中搜索 `mono num` 或直接找表格里的数字。
- **达级标准表**：在 `sprint.html` 搜索 `11.74`、`13.04`，改成官方最新数据。

表格结构是 `<tr><td>…</td></tr>`，每一行一个 `<tr>`，照着格式改数字就行。

### 5. 改联系方式
在 `about.html` 搜索 `邮件交流` / `训练交流` / `线下`，把说明文字换成你的真实信息。
如果加上邮箱链接，格式是：`<a href="mailto:你的邮箱@example.com">…</a>`

### 6. 加一篇新文章
在 `index.html` 找到「精选干货」区块，复制一整个 `<a href="..." class="post reveal"> … </a>` 块，改标题和描述即可。

## 四、上线到公网（自己账号长期维护）

三个平台都免费，任选其一：

| 平台 | 操作难度 | 特点 |
|---|---|---|
| **Netlify** | 最简单：把 `sports` 文件夹直接拖进网页 | 秒出链接，之后每次拖拽即更新 |
| **Vercel** | 简单：注册后导入文件夹或连 Git 仓库 | 支持绑定自己的域名 |
| **GitHub Pages** | 中等：需要会 git | 免费永久，适合长期维护 |

### Netlify 最快的方式（3 步）
1. 打开 https://app.netlify.com/drop
2. 把整个 `sports` 文件夹拖进虚线框
3. 等待几秒，得到 `https://xxx.netlify.app` 链接

> 注意：拖的是 **`sports` 文件夹本身**，不是里面的单个文件，这样相对路径（css/js）才能正确加载。

### 绑定自己的域名
在上面任一平台的后台找到「Domain / 域名」设置，添加你的域名，按提示到域名服务商处加一条 CNAME 记录即可。

## 五、常见问题

**Q：改完打开是白屏 / 样式全丢？**
A：大概率是 `css` 和 `js` 文件夹没跟 HTML 放一起。确保结构与本文第一节一致。

**Q：手机上打开字体很小？**
A：站点已做响应式，如果仍觉得小，检查 `<head>` 里是否有这行（不能删）：
`<meta name="viewport" content="width=device-width, initial-scale=1">`

**Q：改了颜色但没生效？**
A：浏览器缓存，按 `Ctrl + F5`（Mac 是 `Cmd + Shift + R`）强制刷新。

**Q：想加图片？**
A：在 `sports` 下新建 `images` 文件夹放图片，HTML 里写 `<img src="images/xxx.jpg" alt="说明">`。建议图片压缩到 300KB 以内。

**Q：内容有错误想改回来？**
A：建议改之前先把整个文件夹复制一份备份，改坏了用备份覆盖。
